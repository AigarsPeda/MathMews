# Puzzle typography

These static 400, 700 and 900 weights are derived from Nunito’s variable font in the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/nunito

Downloaded 2026-11-01 and instantiated with fontTools varLib.instancer at the corresponding `wght` values. Family, full, PostScript and typographic names are `MewsNunito400`, `MewsNunito700`, and `MewsNunito900` (Regular subfamily), so Expo can select each weight explicitly. Latin and Latvian glyph coverage is retained.

The fonts remain under the SIL Open Font License in OFL.txt. The same notice is included in the app’s third-party asset licenses. Loading is scoped to puzzle routes; pet home typography is unchanged.
