The startup still uses Filament's `NativeCatDisplay`, including its `DefaultLight`, camera and first idle pose. Blender's Cycles render remains the source for the app icon, but its highlights and colors differ from Filament.

`startup-cat-native.png` is the 576 × 576 native portrait capture, with its connected cream background cleared to transparent. The cat pixels retain their native colors. `npm run branding -- --splash-only` generates the 192 × 192 fallback and both launch images from it. The source hashes in `scripts/3d/branding-source.json` bind the capture to the shipped orange cat model; the continuity check fails if that model changes before the capture is refreshed.

To refresh the capture, temporarily hold `SplashGate` open and set `AnimatedSplashCat` playing to false. Capture the simulator after the fallback has been replaced by the native cat, then crop only the 192 pt cat viewport at the device's pixel scale. On the 402 × 874 pt simulator at 3×, the crop is x=315, y=951, width=576, height=576. Clear only the connected background pixels matching #FFF5EB to transparent to avoid a rectangular edge when iOS scales the launch image. Restore the normal loading duration and playback immediately afterwards. Record the new model hash, regenerate the splash assets, run `npm run preios`, and rebuild the native app so its bundled OS launch artwork also updates.
